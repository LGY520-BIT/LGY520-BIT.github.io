# 往事.未完 · 原版博客公开站

从原版 Astro 博客制作的静态公开副本。保留原来的漫画首页、壁纸、看板娘、音乐馆、空间、收藏、追番、阅读工具及浏览器内的工坊/星标。

## 使用
Node.js 24，运行 `npm ci`，然后 `npm run dev`。`npm test`、`npm run audit`、`npm run build` 用于验收。
推送 main 后由 GitHub Actions 部署到 https://lgy520-bit.github.io/ 。

## 公开边界
- 不含原项目 Git 历史、密钥、环境文件、私人运行数据、草稿、本地服务和后台编辑代码。
- AI 反代、站长音乐目录、上传和后台写作仅保留在站长的本机完整版，不开放给访客。
- 音乐馆可播放两首原创曲目，也可选择访客设备上的音频、封面和 LRC；这些文件不会上传。
- 工坊便签、阅读记录和收藏操作只留在访客浏览器。
- 公开源码里的文字和片单都可以被读取。需要保密的内容不能放入此仓库，即使设置 draft 也不安全。
